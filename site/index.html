vr_fire

My capstone project: a VR wildfire simulator for California, part of a larger effort that uses machine learning to predict where a fire will spread.

I'm building the terrain. It turns USGS elevation data into 3D ground on the same 30 m grid the model predicts on, so a forecast lines up with the hills it's burning across.
